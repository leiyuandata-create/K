\section*{Instructions}
\begin{itemize}
\item Attempt all three questions. Show all working.
\item You may use the formula sheet and a calculator.
\item Time: 60 minutes. Start the clock when you turn the page.
\item Each question is graded N0--E8; the total is out of 24.
\end{itemize}
\section*{After the exam}
\begin{itemize}
\item Mark each question with the assessment schedule: count the u, r and t evidence, then give it a grade from N0 to E8.
\item Add the three grades. Cut scores move a little each year: Achievement from about 7--8, Merit 13--14, Excellence 19--20.
\item For every mark lost, write the L-number from your handouts next to it.
\end{itemize}
